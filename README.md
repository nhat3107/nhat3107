## Professional Experience

### Cloud-Native & Kubernetes

- Deploy and operate microservices-based applications across production and staging environments.
- Manage Amazon EKS clusters, managed node groups, Auto Scaling Groups, and AWS Load Balancer integrations.
- Use **Argo CD** for GitOps-based deployment and cluster synchronization, and **Helm** to package and manage applications.
- Use **Istio** for service-to-service communication and traffic management.
- Monitor infrastructure and applications with **Prometheus, Grafana, Loki, and AWS CloudWatch**; troubleshoot deployments and services across environments.

### Windows Cluster & Distributed Computing

Support batch-job workflows on Windows-based infrastructure managed with **HTCondor**, comprising a Central Manager, **30+ worker machines**, and **20+ producer machines**.

- Support batch-job submission, execution, and distributed compute resources.
- Develop Python automation, including orchestration scripts that manage worker uptime to improve utilization and avoid unnecessary operating costs.

### AWS Cloud & Serverless

- Build and support event-driven workloads with **AWS Lambda, Step Functions, and API Gateway**, including high-concurrency Lambda workloads.
- Design VPC networks and segmentation, routing and access, and connectivity between on-premises infrastructure and AWS.
- Work with NAT and Internet Gateways, VPC Peering, Transit Gateway, and Cloud WAN.
- Design and optimize storage across **S3, FSx for Lustre, FSx for NetApp ONTAP, EFS, and EBS**. Automate data lifecycle and movement between FSx ONTAP and S3; achieved approximately **60% storage cost reduction after three months of implementation and optimization**.
- Work with DynamoDB caching and performance optimization, RDS, and Aurora, including zero-downtime database migration strategies.
- Apply standardized infrastructure templates with AWS CloudFormation to improve provisioning consistency and reduce configuration drift.

### Infrastructure as Code & Configuration Management

- Provision infrastructure with **Terraform**, using an S3 remote backend for state, strict IAM role-based access, reusable configurations, and drift detection and alerting.
- Explore and implement Kubernetes-native infrastructure provisioning with **Crossplane** and GitOps reconciliation with **Argo CD**, including declarative patterns in my homelab.
- Use **Ansible** for SSH-based server configuration and administration.
- Manage EC2 instances with **AWS Systems Manager**, using tags to target managed instances and remote commands without direct SSH access.
- Explore pull-based configuration management with **Chef**, cookbooks, recipes, and Chef clients.

### CI/CD Engineering

Design and maintain reusable CI/CD workflows across multiple platforms, integrating build, test, artifact management, quality analysis, and deployment to Kubernetes and AWS.

- **GitHub Actions:** Manage workflows across **100+ repositories**; separate CI and CD, create shared workflows, manage build artifacts, use runner and external-storage caching, and optimize pipeline execution and resource use.
- **Jenkins:** Apply Pipeline as Code and Job as Code patterns, with Groovy scripting to standardize and customize automation across repository groups; integrate with Kubernetes and AWS.
- **GitLab CI/CD:** Build and manage automated build, test, and deployment pipelines.
- **Artifacts and quality:** Work with Sonatype Nexus Repository, Docker Hub, Amazon ECR, and Harbor; integrate SonarQube code coverage and quality analysis.
